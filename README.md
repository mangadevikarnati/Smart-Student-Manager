# Smart Student Manager
Smart Student Manager is a Python-based command-line application designed to efficiently manage student records. The system enables users to add, view, search, and delete student information through an easy-to-use menu-driven interface.

## Features
* Add new student records
* View all student records
* Search students by roll number
* Delete student records
* Interactive menu-driven interface

## Technologies Used
* Python

## Concepts Demonstrated
* Functions
* Lists
* Dictionaries
* Loops
* Conditional Statements
* CRUD Operations
* User Input Handling

## Future Enhancements
* Update student records
* Store data in files
* Database integration using SQLite
* GUI implementation using Tkinter
